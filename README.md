# TheoTown for Android

This repository provides official APK releases of TheoTown for Android devices without access to Google Play.

## Download

You can find the latest APK under [Releases](../../releases/latest).

For most users, we recommend installing TheoTown through [Google Play](https://play.google.com/store/apps/details?id=info.flowersoft.theotown.theotown).

## Important notes

- APKs are provided as an alternative installation method.
- Updates must be installed manually.
- Some features, such as in-app purchases, may be unavailable without Google Play services.

For support and more information, visit [theo.town](https://theo.town).
